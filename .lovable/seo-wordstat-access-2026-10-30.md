# Этап 2: проверка доступа к Яндекс Wordstat

## Статус
Этап не завершён. Проверенных частотностей нет. Сайт и статьи не изменены; этапы 3 и 4 не выполнялись.

## Проверенные факты
- Рынок по согласованному плану: вся Россия.
- На https://wordstat.yandex.ru/ доступна вводная страница и уведомление о возможной временной недоступности части данных. Статистика запросов через чтение страницы не получена. Это не доказывает отсутствие статистики у авторизованного пользователя.
- https://yandex.com/support2/wordstat/ru/content/api-wordstat сообщает о переносе возможностей API в Wordstat API сервиса Yandex Search API и ссылается на https://yandex.cloud/ru/docs/search-api/concepts/wordstat.
- При чтении указанной страницы актуальной документации получена проверка браузера, а не спецификация API.
- Ранее сохранённый токен Яндекса присутствует. Его права на Wordstat не подтверждены: запрос дерева регионов к прежнему документированному адресу https://api.wordstat.yandex.net/v1/getRegionsTree остановлен проверкой HTTPS-сертификата (несовпадение имени хоста). Проверка сертификата не отключалась, ответ с разрешениями не получен. Нельзя утверждать, что токен невалиден или ему не хватает прав.
- Нет доступного подключения Wordstat среди проверенных подключений рабочего пространства.

## Что нужно для продолжения без новой инфраструктуры
Выгрузки CSV из авторизованного Wordstat по четырём исходным фразам, регион «Россия», все устройства:

| Страница Pink Byte | Исходная фраза для выгрузки |
| --- | --- |
| Интернет-магазин | разработка интернет магазина |
| Корпоративный сайт | разработка корпоративного сайта |
| CRM | разработка crm |
| Мобильное приложение | разработка мобильных приложений |

Эти фразы являются отправными точками исследования, а не подтверждённым семантическим ядром. К каждой выгрузке нужны дата, отображаемый период и выбранный регион; если их нет в CSV, приложить снимок настроек. Нужны запросы вместе с частотностями, по возможности также похожие запросы.

## Обработка после получения данных
1. Зафиксировать источник, период, регион, устройства и применённые операторы.
2. Отделить коммерческие формулировки от обучения, вакансий, бесплатных решений и внедрения готовой CRM, если оно не относится к предложению.
3. Сгруппировать подходящие запросы по четырём услугам, отдельно обозначить информационные темы для будущего блога.
4. Не складывать пересекающиеся широкие частотности; не выдавать их за точную частоту фразы или количество людей.
5. Представить результаты второго этапа и остановиться перед удалением статей.

Semrush не использован как замена Wordstat; численные значения не придуманы. Токен и другие секреты в отчёт не включены.
